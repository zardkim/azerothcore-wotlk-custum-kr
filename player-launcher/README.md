# WOW Legends 플레이어용 런처

`../launcher`(서버 운영자용 관리 런처)의 디자인(테마/위젯/커스텀 크롬 타이틀바)만 그대로
가져오고, 기능은 플레이어에게 필요한 것만 남긴 플레이어 배포용 런처입니다:

1. **서버 상태 표시** — 인증서버/월드서버 포트가 열려있는지로 온라인/오프라인만 표시
   (접속자 수는 표시하지 않습니다 — 아래 "왜 접속자 수를 안 보여주나" 참고)
2. **클라이언트 다운로드 및 설치** — 클라이언트가 없으면 폴더 선택 대화상자로 설치 위치를
   직접 고르게 한 뒤, 7-Zip SFX(자동압축풀림) exe를 받아 그 폴더에 조용히 설치. 다운로드
   중에는 진행률(%, MB)을, 압축을 푸는 동안에는 "설치하는 중..." 애니메이션을 보여줍니다
   (7-Zip SFX 모듈은 압축 해제 자체의 진행률을 알려주지 않아서, 정지된 것처럼 보이지 않게
   막대가 계속 움직이는 정도로만 표시합니다).
3. **다운로드 이어받기** — 네트워크가 끊기는 등으로 다운로드가 중간에 실패해도 받다 만
   파일을 지우지 않고 그대로 둡니다. 클라이언트 파일이 커서(수 GB) 처음부터 다시 받으면
   오래 걸리므로, 재시도하면 서버가 이어받기(HTTP Range)를 지원하는 한 중단된 지점부터
   이어서 받습니다(지원하지 않는 서버라면 자동으로 처음부터 다시 받습니다).
4. **설치 여부 확인** — 마지막으로 설치했던 폴더(`install_state.json`에 저장)에 실행파일이
   실제로 있는지 매번 시작할 때 확인해서, 있으면 다운로드 버튼 대신 **PLAY**를 보여줌
5. **PLAY** — 확인된 설치 위치에서 클라이언트 실행
6. **설정(⚙) — 설치 폴더 재지정** — 타이틀바의 톱니바퀴 아이콘을 누르면, 게임 폴더를
   나중에 다른 위치로 옮긴 경우 그 새 위치를 다시 지정할 수 있습니다. 다시 다운로드할
   필요 없이 런처가 추적하는 위치만 바꿔서, 그 폴더에 실행파일이 있으면 바로 PLAY로
   전환됩니다.
7. **렐름리스트 자동 동기화** — 웹사이트(`ac-web`)의 공개 API에서 현재 접속 주소를 가져와
   설치 시 및 실행할 때마다 클라이언트의 `realmlist.wtf`를 자동으로 맞춰줍니다. 운영자가
   웹사이트 관리자 페이지나 DB에서 렐름 주소를 바꾸면, 플레이어는 아무것도 안 해도 다음에
   런처를 열 때 자동으로 반영됩니다.

운영자용 런처에 있던 서버 시작/중지, GM 콘솔, 계정 관리, 원격 SSH 관리, 게임 설정 편집
등은 전혀 없습니다 — 플레이어가 건드릴 이유가 없는 기능이라 아예 뺐습니다. 로그인/게임 내
자동로그인 연동도 하지 않기로 했습니다(웹사이트 로그인과는 완전히 별개로 동작합니다).

## 실행 방법

```bash
pip install -r requirements.txt
```
- **`런처 실행.vbs`** 더블클릭 (콘솔 없이 실행)
- 또는 `python app.py` (디버그용, 콘솔 표시)

## exe로 빌드하기

```bash
build.bat
```
`dist\WOW Legends.exe` **단일 파일**이 만들어집니다(`--onefile`). `assets/`와
`config/`가 exe 안에 그대로 구워지므로(`--add-data`), 이 exe 하나만 배포하면 됩니다 —
플레이어는 이 파일 하나만 내려받아 실행하면 됩니다. **빌드 전에 반드시**
`config\config.json`을 실제 서버 정보로 채우세요(빌드 후에는 exe 안에 박혀서 바뀌지
않습니다):

```json
{
  "auth_host": "xbox.pe.kr",
  "auth_port": 3724,
  "world_host": "xbox.pe.kr",
  "world_port": 8085,
  "client_dir": "client",
  "client_exe": "Wow.exe",
  "download_url": "https://.../client.exe",
  "realmlist": "xbox.pe.kr",
  "realmlist_api_url": "https://xbox.pe.kr:11220/api/realmlist"
}
```

- `auth_host`/`auth_port`, `world_host`/`world_port`: 상태 확인용 (같은 값이면 됩니다)
- `client_dir`: 아직 한 번도 설치한 적 없을 때 폴더 선택 대화상자가 기본으로 보여줄
  위치(exe 기준 상대경로)일 뿐, 실제 설치 위치는 아닙니다 — 설치 시 사용자가 폴더
  선택 대화상자에서 원하는 곳으로 직접 바꿀 수 있습니다.
- `client_exe`: 설치 폴더 안에서 실행할 exe 이름. 이 이름이 없어도 `Wow.exe`/
  `Wow_hd.exe`는 자동으로도 찾습니다(`config.py`의 `find_client_exe()`) — 설정(⚙)에서
  이미 설치되어 있는 폴더를 직접 지정했을 때, 그 폴더의 실제 실행 파일 이름이 이
  값과 달라도(예: HD 클라이언트) PLAY로 정상 인식되게 하기 위함입니다.
- `download_url`: 클라이언트 배포 파일(7-Zip SFX exe) 다운로드 주소
- `realmlist`: `realmlist_api_url`을 못 가져올 때(또는 비워뒀을 때) 대체로 쓰는 고정 접속 주소
- `realmlist_api_url`: 웹사이트(`ac-web`)의 `/api/realmlist` 공개 엔드포인트 주소. 채워두면
  이 값이 `realmlist`보다 항상 우선합니다 — 비워두면 동기화 없이 `realmlist` 값만 씁니다.

운영자용 런처와 달리 **이 config.json은 빌드에 그대로 포함됩니다** — 플레이어가 직접
입력할 항목이 없어서, 배포 전에 운영자가 미리 채워서 exe와 함께 나눠주는 방식입니다.

## exe를 실행하면 자동으로 C:\wow_launcher에 설치됨

다운로드 폴더 등 아무 곳에서나 이 exe를 실행하면, 실행 위치가 `C:\wow_launcher\WOW
Legends.exe`가 아닐 경우 자기 자신을 그 경로로 복사하고 그 복사본을 다시 실행한 뒤
원래 프로세스는 종료합니다(`app.py`의 `ensure_installed()`). 즉 플레이어는 설치
프로그램을 따로 실행할 필요 없이, 내려받은 exe를 그냥 실행하기만 하면 이후로는 항상
`C:\wow_launcher`에서 실행됩니다(바탕화면 바로가기를 만들 때도 이 경로를 가리키면
됩니다). 이 자동 설치 로직은 클라이언트 게임 파일이 아니라 **런처 exe 자신**에만
적용됩니다 — 클라이언트 설치 위치는 아래처럼 플레이어가 직접 고릅니다.

이 exe를 웹사이트(`ac-web`)에서 내려받게 하려면, 파일 서버나 웹사이트에 업로드한 뒤 그
주소를 관리자 페이지의 "데스크톱 런처 다운로드 주소" 입력란에 넣으면 됩니다. 로그인한
상태에서 홈 화면의 "지금 플레이하기" 버튼을 누르면 이 주소로 이동합니다(모바일에서는
대신 안내 메시지만 표시하고 이동하지 않습니다).

## 설치 위치는 어떻게 기억되나

플레이어가 "다운로드" 버튼을 누르면 먼저 폴더 선택 대화상자가 뜨고, 고른 위치에 설치가
끝나면 그 경로가 exe 옆의 `install_state.json`에 저장됩니다(`state.py`). 다음에 런처를
실행하면 이 파일에 저장된 경로에 `client_exe`가 실제로 있는지 확인해서, 있으면 바로
PLAY 버튼을 보여줍니다 — 매번 새로 물어보거나 기본 위치만 확인하지 않습니다.
`install_state.json`이 없거나(최초 실행) 그 경로에 파일이 없으면 다운로드 버튼을
보여줍니다.

## 클라이언트 배포 파일(7-Zip SFX) 만드는 법

**반드시 "단순 압축 풀기" SFX 모듈을 써야 합니다.** 7-Zip이 기본 제공하는 설치형
SFX(`7zS.sfx`, 마법사 UI로 뜨는 것)는 명령줄 스위치를 무시하고 내부에 미리 정해둔
동작만 하기 때문에, 이 런처가 조용히(대화상자 없이) 설치할 수 없습니다.

1. 클라이언트 파일 전체를 7z로 압축: `7z a client.7z <클라이언트 폴더>\*`
2. 7-Zip 설치 폴더(보통 `C:\Program Files\7-Zip`)의 `7z.sfx`를 SFX 모듈로 사용해서 합치기:
   ```
   copy /b "C:\Program Files\7-Zip\7z.sfx" + client.7z client.exe
   ```
3. 이 `client.exe`를 웹사이트나 파일 서버에 올리고, 그 주소를 `config.json`의
   `download_url`에 넣으면 됩니다.

런처는 다운로드한 exe를 `<sfx> -y -o<설치폴더>`로 실행합니다(`-y`=전체 동의, `-o`=대상
폴더) — 이 스위치들은 7-Zip 압축 해제 엔진 자체가 받는 표준 명령줄 옵션이라, 위 방식대로
만든 SFX라면 대화상자 없이 조용히 풀립니다.

## 왜 접속자 수/가동시간을 안 보여주나

운영자용 런처는 `soap_client.py`로 `server info` GM 명령을 실행해서 접속자 수·가동시간을
가져옵니다. 이건 **GM 계정으로 인증**해야 하는데, 이 계정 정보를 불특정 다수에게 배포되는
exe 안에 심어두면 그 exe를 분석해서 누구나 GM 권한을 빼갈 수 있는 심각한 보안 문제가
됩니다. 그래서 이 플레이어용 런처는 GM 인증이 필요 없는 **TCP 포트 확인**(온라인/오프라인
만 판단)만 사용합니다(`server_status.py`). `soap_client.py`는 나중에 참고할 수 있도록
파일은 남겨뒀지만 이 런처에서는 쓰지 않습니다.

## 파일 구성

```
player-launcher/
├─ app.py                메인 UI (Tkinter) — 상태 패널 + PLAY/다운로드 버튼 + 설정(⚙)
├─ settings_dialog.py       설정(⚙) 클릭 시 뜨는 대화상자 — 설치 폴더 재지정
├─ config.py               config\config.json 로드 (배포자가 미리 채우는 기본값)
├─ state.py                 install_state.json 로드/저장 (사용자가 고른 실제 설치 경로)
├─ downloader.py            HTTP 다운로드(진행률 + 이어받기) + 7z SFX 조용히 설치
├─ server_status.py          TCP 포트로만 온라인/오프라인 확인 (GM 계정 불필요)
├─ realmlist_sync.py          ac-web의 /api/realmlist에서 최신 접속 주소를 가져옴 (인증 불필요)
├─ theme.py, widgets.py, tooltip.py, paths.py   운영자용 런처에서 그대로 가져온 디자인 모듈
├─ status.py                운영자용 런처의 process_manager.py 상수 중 theme.py가 필요로 하는
│                            RUNNING/STOPPED 등만 뗀 작은 모듈
├─ soap_client.py             (미사용, 참고용으로만 보관)
├─ config/config.json          실제 서버 주소 등 (빌드에 포함됨)
├─ assets/                      logo/background/left_side/icon (운영자용 런처와 동일 자산 사용)
└─ build.bat, 런처 실행.vbs
```
